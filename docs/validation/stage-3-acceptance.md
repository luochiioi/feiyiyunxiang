### 阶段三完整联调

新模板按[文化任务解锁调整计划](../superpowers/plans/2026-11-11-stage-3-culture-unlocks.md)验收。文化任务计入探索进度，打卡与私密日记仍按到访单独记录。

调整后 43 项 Node 测试通过，微信开发包和后台 Web 构建通过。微信开发者工具用本机内存服务的两条测试路线复核了零打卡进入辨认题、错答提示和答对解析紧跟所选选项，以及第四、五幕各自解锁。

1. 打开 `app/unpackage/dist/dev/mp-weixin`。保持游客态，从地图进入「剧情」。打开第一幕，点继续，分别走瓷砖和绣线分支。退出后从同一对白恢复。用「上一段」返回选择，用「重读」回本幕开头。第一幕可以在云端服务暂不可用时阅读。游客查看目录时第二至六幕显示路线门槛。
2. 使用已发布的「澳门文化任务联调」和「湖南文化任务联调」验收。新增测试路线时用独立后台账号登录，澳门路线配置至少一个打卡点，建议配置两点以覆盖非首站打卡。湖南路线配置联调地图点位。测试坐标使用联调允许的位置，明确标为开发测试。
3. 在后台分别载入澳门和湖南模板。校验并预览，试读选项和对白，检查辨认题答案及知识卡内容。临时改坏节点引用、答案或场景跳转，校验应拒绝。修正后保存草稿，再发布该修订。前台普通微信账号不能读取草稿和预览接口。
4. 从「路线 → 澳门测试路线」直接进入配色，切换纹样和配色，退出重进后恢复未提交的选择。保存后进度增加一次，「我的 → 文化作品」可回看，第三幕解锁。进入瓷砖纹样题，答错应显示观察提示，答对解锁第四幕。此时地图各点仍未打卡，第二幕仍锁定。使用模拟定位在任一点完成定位照片打卡，有两点时优先选非首站，验证第二幕解锁。
5. 从「路线 → 湖南测试路线」直接进入湘绣辨认。答错显示观察提示，答对后第五幕和学习卡开放。逐张打开热点并标记已读。读到一半退出重进，已读数量保持。学完四张，第六幕解锁。核对文化任务进度及独立的地图打卡状态。
6. 在已解锁章节内读到一半退出，重新进入后恢复。保持旧探索，后台修改一个章节标题和任务门槛，再发布新修订。旧探索用原门槛和断点，新账号首次进入使用新修订。分别核对地图、路线、已打卡标记和个人日记。
