## 已实现

- fy-api 为阶段二入口，领域逻辑、持久化和安全模块分离。微信 code 服务端交换、uni-id 会话、数据库校验令牌撤销/账号状态、管理员实时权限、管理员密码 scrypt 和登录限流。
- 后台桌面登录、博物馆资料与有序定位照片节点草稿、修订冲突检查和固定版本发布。当前仅开发测试发布；正式内容仍被核实门禁拒绝。管理员令牌只存内存。
- run 固定路线版本；独立 checkins、diary、media、请求去重记录。服务端校验定位、范围和媒体归属，事务内保存打卡/日记/媒体引用；进度从独立记录计算。
- 受控服务端媒体上传，1MB JPG/PNG 格式/大小检查、私有目录门禁与 AES-GCM 加密。读取只按账号解密返回，不返回存储地址。该流程不识别展品、不证明拍摄时间，也不能完全防伪造定位。
- 小程序路线/点位、登录/退出、开始或继续探索、照片与备注草稿、位置提交、日记和私密照片读取接入真实接口。会话到期重新取 code；提交失败沿用请求编号、保留照片和备注。跨页返回保留地图状态。
- 社区、剧情、旅伴、作品仍标明待开发。关闭阶段一演示，不在云端失败时伪造数据或成功状态。

## 当前限制

- 尚无授权后的真实微信账号、两账号越权、真实私有目录、上传弱网和支付宝事务联调结果，不能宣布真实探索闭环验收通过。
- 草稿列表/目录/日记当前单次最多读取 100 条，日记倒序展示；后续运营量增长前补游标分页。照片未绑定/上传响应丢失可能留下加密孤立对象，需按清单配置受控清理；不会因孤立对象产生打卡成功状态。
- 博物馆信息随路线草稿/版本一起管理，尚无独立馆方资料库。正式馆名、位置、范围和内容核实材料未齐，当前只允许开发测试版本。
