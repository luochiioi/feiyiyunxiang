# 第五阶段社区审核与治理验收

基线为 origin/codex/stage-4 的 fc5df8b，开发分支为 codex/stage-5。

## 实现口径

- 公开列表、详情、分享和图片通过同一云端判断读取当前审核通过版。新版单独审核，驳回时继续展示旧版。通过时事务更新版本状态与公开指针，下架或作者撤下时清除公开指针。
- 作者可在「我的帖子」查看待审和驳回结果。日记选图须由本人主动选择，云端创建独立加密副本，剥离 JPEG 与 PNG 的位置元数据。帖子接口仅接收标题、正文和选图来源，不导入日记坐标或公开原凭证标识。
- 评论归一化后优先执行拒绝规则。允许词条完整匹配评论时可直接公开，其余评论按待审规则判断。限流与评论写入使用同一事务，默认间隔 10 秒、滚动 10 分钟 20 条、相同内容 5 分钟去重。待审评论不计入公开数量。
- 榜单按个人探索路线计算，同一路线的多个完成记录只计一次，路线需要完成该次探索所固定的点位与文化任务。同分采用 1、1、3 排名。
- 后台 admin 可配置评论词库和限流。reviewer 可对照版本、审帖、审评、处理举报和社区禁言。角色由独立后台会话校验，治理变更写入审计记录。

## 九图与运营后台补充验收

- 标题、正文、照片任意一项即可提交。空表单此前会禁用提交按钮且无提示，当前在微信开发者工具点击后立即显示补充内容提示。
- 在微信开发者工具从本机测试素材分两次选入九张照片，页面显示 9/9 和九宫格预览。旧版单图帖子仍能从当前云端读取和显示。
- 照片逐张上传。相册照片超过 1 MB 时尝试压缩，云端继续限制单图为 1 MB 的 JPG 或 PNG。已暂存照片可在同一次发帖重试中复用，暂存有效期为 24 小时。
- 运营后台新增工作台和用户管理。管理员可查找、筛选、禁言、停用和恢复账户，并跳转到按用户筛选的审核记录。停用或恢复都会撤销既有会话。
- 补充后本地 Node 测试 77 项通过。微信开发包、AppID 校验和后台 Web 本地编译通过。
- 真机九图上传、真实云端从暂存到审核发布、后台计数及账户操作仍待联调。联调需先将新增 fy-community-uploads 集合、索引和 fy-api 同步到开发云。过期未绑定媒体的自动清理留在阶段六的资源清理范围。

### 照片上传故障复查

- 相册多图与日记单图均在第 1 张失败。HBuilderX 从当前支付宝开发云读取的集合清单缺少 fy-community-uploads。相册和日记会先读取该集合，再处理图片。旧提示把这一阶段的异常显示成了网络重试。
- 本地已区分暂存不可用、对象存储上传失败和原照片读取失败。新社区副本存入已配置的私有目录 fy-private/community，保留独立加密文件及按版本授权的读取方式。
- 78 项 Node 测试通过，其中新增测试模拟暂存集合缺失与存储 SDK 拒绝，并核对两者返回不同错误。补齐开发云集合和云函数后的实际上传仍待验证。
