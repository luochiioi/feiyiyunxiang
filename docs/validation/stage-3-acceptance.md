## 微信开发者工具

本轮通过微信开发者工具的自动化接口验证游客目录、两个开场分支、回退、结尾及重新打开阅读页后的断点恢复。另用独立的本机构建副本连接内存服务，验证澳门路线任务入口、打卡前锁定、合成打卡后解锁、配色草稿写入、作品保存、路线进度更新及作品页回看。真实微信账号、定位、照片及支付宝云事务留待联调。

1. 打开 `app/unpackage/dist/dev/mp-weixin`。保持游客态，从地图进入「剧情」。打开第一幕，点继续，分别走瓷砖和绣线分支。退出后从同一对白恢复。用「上一段」返回选择，用「重读」回本幕开头。第一幕可以在云端服务暂不可用时阅读。游客查看目录时第二至六幕显示路线门槛。
2. 阶段三云端联调获授权并完成后，用新建的开发测试路线验收。后台独立账号登录，澳门测试路线配置两个打卡点，湖南配置一个。测试坐标使用联调允许的位置，明确标为开发测试。新建路线可以避免误用已有阶段二探索。
3. 在后台分别载入澳门和湖南模板。校验并预览，试读选项和对白，检查辨认题答案及知识卡内容。临时改坏节点引用、答案或场景跳转，校验应拒绝。修正后保存草稿，再发布该修订。前台普通微信账号不能读取草稿和预览接口。
4. 从「路线 → 澳门测试路线」点配色。首个定位照片打卡前显示锁定，第二幕也未解锁。使用模拟定位完成首个点，打开第二幕。进配色切换三种纹样与配色，退出重进后恢复未提交的选择。保存后路线进度只增加一次，「我的 → 文化作品」可回看，第三幕解锁。完成第二个定位点后第四幕可读。
5. 从「路线 → 湖南测试路线」完成定位照片打卡，进入辨认题。答错后可重试，答对后第五幕和学习卡开放。逐张打开热点并标记已读。读到一半退出重进，已读数量保持。学完四张，第六幕解锁，路线进度完成。
6. 在已解锁章节内读到一半退出，重新进入后恢复。保持旧探索，后台修改一个章节标题和任务门槛，再发布新修订。旧探索用原门槛和断点，新账号首次进入使用新修订。分别核对地图、路线、已打卡标记和个人日记。

## 真机复测

在获授权的开发环境分别用两台设备或两个微信账号验证。A 的作品、卡片进度、正式章节断点和私密照片不能由 B 读取。检查弱网下的配色提交、答题和阅读存档重试。核对微信登录、授权定位、地图返回视野和两地路线进度。

按[阶段二部署清单](stage-2-deployment.md)抽查一条已有正常照片，再新建一条私密打卡，退出并重新打开，两条都应显示照片。已记录原文件缺失的历史打卡应保留时间、备注和进度，显示照片不可用。
