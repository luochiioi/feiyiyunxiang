# AI 非遗猜图与漂流瓶单人试用

2026-11-12

## 微信开发者工具里的试用入口

在「旅伴」进入「AI 非遗猜图」或「漂流瓶」。开发构建显示「单人试用」，同一账号可以走完发起与接收两边的操作。正式构建隐藏单人试用。陌生人配对仍在待办。

## AI 非遗猜图

1. 从湘绣或葡萄牙瓷砖选一种工艺，从花卉或鸟选一个纹样。由 SiliconFlow 根据工艺和纹样生成图片，标明 AI 生成。
2. 正常模式发给已接受的好友。单人试用时可把题发给自己，然后在收件箱打开。收件页展示图片和选项。新题是单题八选一，干扰项加入蓝印花布及青花瓷；已发出的题保留原选项。
3. 提交后显示正确组合。答对时展示对应工艺的科普。正式好友题按原规则免除一项待处理的 PK 失败任务或发放一张提示券。单人试用题只展示模拟奖励结果，不写入正式钱包或 PK 记录。
4. 已发送的旧题仍使用原选项。弱网重试沿用同一次发题记录。真实图片服务不可用时显示失败原因，并保留重试入口。

验收顺序是「选工艺和纹样 → 给自己发题 → 收件 → 猜错一题 → 猜对一题 → 查看科普」。另需用两名真实好友验证发题权限、免罚、提示券和第三账号不可读图。

## 漂流瓶

1. 投瓶时选择「附近」或「跨地区」，并选澳门或湖南路线。附近模式经同意取得一次定位，仅使用粗略区域比较距离。跨地区模式按用户选择的路线匹配。
2. 匹配前只显示瓶子的地区和路线。配对后双方各自确认，任一方拒绝、撤回或超时即结束本次邀请。双方同意后才成为旅伴并进入合作打卡。
3. 澳门和湖南跨地区合作时，各自使用发布时固定的本地路线修订。附近匹配时，两人可走同一馆的路线，各自保有独立进度。任一方退出可结束当前合作，双方的私密打卡照片仍分别受权限保护。
4. 单人试用使用同一账号操作「我」和「示范旅伴」。试用页展示投瓶、接收、接受、拒绝和退出，匹配资料与进度停留在试用环境。

验收顺序是「投瓶 → 切换示范角色接收 → 双方确认 → 查看各自路线 → 退出」。另走一次拒绝流程。正式验收需要两个测试账号分别完成附近和跨地区匹配，并验证第三账号看不到邀请及私密照片。

### 正式配对接入合作打卡（待确认）

现有好友合作用同一个发布版本给澳门、湖南两个席位分配节点；正式上、下集是各自独立的发布版本。正式漂流瓶需要为每位成员记录路线 ID、固定修订和独立探索 ID。同馆配对也会有两个独立探索，避免用「对方必在另一地区」来推断身份或任务。现有合并路线团队及其历史探索继续按原快照读取。

| 场景 | 验收结果 |
| --- | --- |
| 投瓶、拾取 | 用户主动参与。跨地区按所选馆路匹配。附近模式须先取得定位同意，只用粗略区域判断匹配，拒绝定位仍可选择跨地区。 |
| 双方确认 | 两人分别同意后才创建合作和两个探索。同意、撤回或过期同时发生时，以云端事务提交的状态为准；重试只返回原结果。 |
| 进入、退出 | 两人从「旅伴」打开各自的正式路线，重新进入恢复原进度。任一人拒绝、撤回或过期后可以另配；开始后退出走既有合作退出流程。 |
| 访问范围 | 配对状态只向双方可见，画面显示匹配所需的昵称和地区，不返回经纬度、微信标识、私密照片或对方的探索 ID。第三账号无法查询或改变配对、读取照片。 |
| 版本隔离 | 两馆发布新修订后，进行中的合作继续读已固定的修订。个人、好友合作、漂流瓶合作与 PK 的进度分别保存。 |

双账号真机验收包含同馆与跨地区各一次，以及拒绝、超时、重复接受、退出和第三账号访问拒绝。附近范围及正式启用时机待产品方确认。
