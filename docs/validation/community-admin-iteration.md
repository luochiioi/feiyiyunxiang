# 社区与管理端 A1–A5 本机验收

基线：`origin/main` 的 `66546da`。验证日期：2026-11-18（澳门时间）。本轮只编译和验证本地产物。

| 项目 | 本机验证 |
| --- | --- |
| 工作台和队列 | 45 条可审核版本与 25 条历史待审记录混排，工作台返回 45；队列按 20、20、5 返回，用户筛选后没有漏项或重复。Chrome 用 Web 构建产物测试工作台跳转、第二页失败后重试、空队列及返回刷新。 |
| 审核、媒体和举报 | Node 验证并发审核只有一个状态变更及审计、拒绝保留老版、通过切版、下架后旧链接与社区图片失效。举报以存储的版本和评论归属为准。覆盖旧单图、旧评论、相册混合私密日记九图、模拟存储失败后重试、社区副本去元数据与原图隔离。Chrome 模拟第 9 张图首次读取失败，以及成功审核后队列刷新失败，重试没有重新提交审核。 |
| 用户、禁言和审计 | Node 验证精确公开 ID、无公开资料账户、禁言时长边界、旧会话撤销、非运营停用不可恢复、后台角色实时校验、审计与禁言按账号隔离，以及事务失败不产生成功审计。Chrome 测试用户跳按账号筛选的队列与返回、确认停用、停用写入成功而列表和详情读取失败；单独重试读取后，停用写入次数仍为一次，第二页账户及所选详情仍可见。 |
| 词库与限流 | Node 验证仅管理员写入、并发保存只接受一个修订、归一化重复词条拒绝、拒绝优先级、评论间隔、窗口上限和去重。Chrome 模拟保存收到版本冲突，输入值保留。既有词库与限流配置沿用同一集合。 |
| 作者与「我的」 | Node 验证审核原因和公开版提示仅作者可见，陌生账号不能打开待审版本或读取原日记照片。澳喵服务原有回归覆盖新会话读取、重复领取、不同账号和换装资格；探索档案原有回归覆盖空账号、私密照片和历史探索。微信开发包编译 21 页，源码和编译产物 AppID 一致。 |

继续使用独立后台会话，每次调用按后台账号的当前角色校验。帖子、评论、举报、账户和禁言的审计和状态写入同一事务。新审计写入从对象归属确认的可选 `targetUid`；旧事件和没有明确账号对象的词库事件仍在全局可见。按用户查看历史时不回填或猜测旧数据。禁言使用账号主键查询。待审帖子沿用版本集合 `status_order`、`uid_status_order`，逐页核对帖子指针，无需迁移历史记录；开发云应测量实际待审量下的工作台响应时间。

获授权后的联调顺序：

1. 在目标支付宝云空间确认现有集合及索引，应用 `fy-community-audit` 可选 `targetUid` Schema，创建 `targetUid ASC, order DESC` 索引并等索引就绪。保留现有 `order` 索引及全部旧审计。
2. 更新 `fy-api`（包含 `community-review-queue.js`），随后联调 Web 和小程序包。用两名作者、审核员、管理员检验权限、真实事务竞争、举报旧版本、私有存储和会话撤销。
3. 在微信真机验收九图弱网重试、私密日记原图和社区副本、旧分享失效、同账号重新登录后的澳喵领取与档案恢复。确认默认澳喵和暂未开放的换装保持原状。用后台真实账号验收列表刷新失败、词库冲突输入保留，以及多页用户和审计查询。
