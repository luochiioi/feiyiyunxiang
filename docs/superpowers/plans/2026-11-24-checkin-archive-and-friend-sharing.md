# 探索档案与好友帖子分享实施计划

> **执行技能** 使用 superpowers:executing-plans 按任务验证。

**目标**　让用户按日期浏览打卡并回看单条记录，同时可以从公开帖子向已接受的站内好友发送可跳转的消息。

**实现**　uni-app x 列表和详情复用私有日记与媒体 API，详情通过打卡 ID 读取本人记录。好友分享沿用好友关系、公开帖子读取规则及消息中心。

**范围**　使用 `codex/checkin-archive-and-friend-sharing`。保留现有工作区改动、微信分享入口及原有审核通知。发布日期和云端部署单独确认。

## 任务一　探索档案

- [x] 使用 `explorationArchive` 获取已有记录，按设备本地日期倒序分组，支持全部、馆内和馆外筛选。列表行显示打卡名、场馆、时间及照片状态，文化作品和旅伴保留紧凑入口。
- [x] 在 `pages.json` 注册单条详情。新增 `explorationArchiveDetail({id})` 并校验服务端记录归属，复用旧记录的场馆和类型补齐逻辑。
- [x] 实现详情中的按需读取照片、单独重试和原路线跳转。照片加载成功后才显示「用这张图发帖」。无照片和旧记录可独立显示。
- [x] 验证跨日期、筛选、无照片、他人 ID、旧记录以及返回列表后保留筛选和滚动位置。

## 任务二　帖子分享给站内好友

- [x] 复用已有好友列表并筛出已接受的好友。帖子详情提供「分享给好友」，每次选一位确认发送，保留原微信分享。
- [x] 新增 `communityShareToFriend({postId,code})`。发送事务校验当前公开版本、双方仍为有效好友和账号有效性。同一发送人、好友及公开版本的重复发送复用原消息，保留已读状态。
- [x] 消息中心显示「好友分享了帖子」和发送者。进入详情可打开当前公开原帖。帖子下架或删除后，消息保留，跳转不可用。
- [x] 验证陌生人、待确认好友、未发布内容、重复发送、收件人权限、已读及帖子撤下。

## 任务三　集成验证

- [x] Node 214 项通过，微信开发包和 App Web 构建通过。
- [x] Edge 使用模拟数据验证列表筛选、打卡详情、无照片状态、原列表滚动位置、好友发送、消息已读和原帖跳转。可用 `scripts/validate-checkin-friend-browser.js` 复跑。
- [ ] 开发云更新 `fy-api` 后，用两个微信账号验收真实分享、照片回看和名单隔离。两项功能沿用现有集合与字段。
