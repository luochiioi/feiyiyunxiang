## 阶段二实施范围

完成第一条真实探索闭环，按依赖编写阶段二实施计划并直接实现。

1. 微信 code 换服务端会话、登录态恢复和过期处理。客户端不持有 AppSecret 或 session_key。保持游客可浏览，账号受限操作有明确登录与恢复路径。
2. 最小桌面运营后台，含受控管理员登录及权限、博物馆和路线节点的草稿编辑与发布。普通用户不能调用管理接口。首个管理员经受控初始化产生。
3. 新的内容版本、route_run、独立 checkins、私密媒体及日记数据结构。旧数据不迁移。两端调用同一套受控业务接口，云端源码优先以 app 目录为唯一来源。
4. 定位加照片的私密打卡。云端校验身份、位置范围、照片归属及节点版本，处理重复提交、失败重试和并发一致性。照片默认本人可见。
5. 真实日记与路线进度，返回地图保留视野。标明真实数据和后续待开发操作。
6. 验证真实微信登录、会话过期、定位拒绝、上传失败、重复提交、跨用户越权和后台发布。没有部署授权时，先完成本地实现、检查和可审阅的部署清单，明确哪些联调仍待执行。

博物馆图集和剧情大图按需从云端读取，私密凭证经受控权限访问。正式馆方资料不足时，仅创建明确标记的开发测试草稿。社区审核、正式剧情、好友合作和 PK 按路线图后续阶段实施。
