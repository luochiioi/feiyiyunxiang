# 海丝瓷绣·一念归期｜两馆展品彩蛋

彩蛋接在两集现有馆外打卡之后。默认可拍照。每馆完成一题展品观察和一张取景照，解锁一项可在原文化任务使用的内容。

## 上集 · 澳门博物馆

- **展品**｜明代青花克拉克瓷盘，馆藏编号 MM5197。馆藏页记录这件瓷盘直径 48 厘米，盘上有狮子和花卉。以外销瓷随商船流通的故事引出盘面装饰，接回上集的蓝白瓷砖配色。[澳門博物館藏品頁](https://www.macaumuseum.gov.mo/collections/81777)
- **取景**｜在一楼「澳门的早期历史」的「国际通商口岸」展区寻找外销瓷。目标盘在展时，从展柜前的公众参观区拍一张能看到盘沿和部分纹样的照片。目标盘换展时，改拍该展区可见的外销瓷或该主题展板。馆内手持拍摄，关闭闪光灯，不用脚架和自拍器。[常設展覽](https://www.macaumuseum.gov.mo/exhibitions/75001) · [拍攝須知](https://www.macaumuseum.gov.mo/visit/photographmustknow)
- **观察题**｜「瓷盘边沿用一道道边框把纹样分成若干区，这种装饰叫什么？」选项为「开光」「镂空」「描金」。答对后显示一张解释边框和纹样分区的原创图示。[澳門博物館藏品頁](https://www.macaumuseum.gov.mo/collections/81777)
- **解锁**｜在「蓝白瓷砖配色」加入「开光纹样框」，让玩家为边框和框内图案分别选色，并保存自己的设计。

## 下集 · 湖南湘绣博物馆

- **展品**｜双面全异绣《杨玉环》。馆方资料记载，作品由湖南湘绣博物馆收藏陈列。用它介绍同一块底料的正反两面可以呈现不同画面的工艺。[湖南湘绣博物馆馆情](https://hnembmusuem.com/aboutUs.html) · [湖南省政府湘绣介绍](https://www.hunan.gov.cn/hnszf/jxxx/hxwh/sgy/201711/t20171111_4685293.html)
- **取景**｜到长沙市芙蓉区车站北路 39 号入馆，依当日导览或展签找《杨玉环》。从展柜外的公众通道拍一面绣品或展签即可。另一面可从开放通道观察，无需拍两张。作品换展时，可选当天展出的其他双面全异绣或对应的工艺展板。默认用手机手持拍摄，关闭闪光灯。[湖南湘绣博物馆](https://www.hnembmusuem.com/index.html) · [参观预约](https://www.hnembmusuem.com/visitReservation.html)
- **观察题**｜「双面全异绣的两幅不同画面怎样做出来？」选项为「在同一块底料的正反面绣制」「把两张绣片背对背缝合」「同一面绣两遍」。答对后用原创双面示意说明这项工艺。[湖南省政府湘绣介绍](https://www.hunan.gov.cn/hnszf/jxxx/hxwh/sgy/201711/t20171111_4685293.html)
- **解锁**｜在「湘绣观察卡」加一张「一绣两面」彩蛋卡。翻面比较构图和色彩，保存一条自己的观察。

## 提交与判定

1. 路线详情在馆外打卡完成后显示「展品彩蛋」。玩家读故事、选答案、用小程序相机拍一张，再一起提交。换展时在同一页选择「拍摄同主题展品或展板」，解锁相同。
2. 云端按该探索固定的路线修订核对题目、答项、前置打卡和照片归属。答错保留照片供重试。重复提交只解锁一次。照片和观察留在自己的探索内。
3. 取景照片作为私密到访凭证，学习结果由观察题判定。系统记录「已完成展品观察」，不把一张照片当作对具体藏品真伪的认证。两馆的照片上传、换展替代、错答重试与解锁仍需现场验收。
4. 小程序用原创工艺图示和馆方页面链接呈现展品背景。实际展柜和在展状态以当日导览为准，文案不写固定展柜编号。

### 验收场景

- 上集提交正确照片和「开光」，在既有配色任务看到开光纹样框。下集完成同样流程后看到可翻面的「一绣两面」卡。
- 两馆分别验证错答重试、换展路径、弱网重复提交、离开重进和跨账号读图被拒绝。正式彩蛋按新修订发布，已有探索沿用其固定版本。
