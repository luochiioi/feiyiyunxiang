# 阶段三实施计划

从 `stage-2-baseline`（`d0354d3`）建立 `codex/stage-3`。沿用新版两端身份、路线版本和私密打卡，旧工程仅作阅读器参考。

1. 澳门纵切。路线详情展示文化任务，服务端按固定探索版本和已完成点位开放蓝白瓷砖配色。保存作品、完成任务和更新进度在同一事务内，作品可从个人页回看。用本地测试覆盖打卡、授权、保存重试和版本固定。
2. 扩展剧情与湖南任务。移植旧阅读器的对白、选择、历史回退和重开结构。开放游客第一幕，澳门与湖南分别解锁后续章节。按探索版本保存断点。完成湘绣辨认及四张学习卡，补本地收尾文案。
3. 后台与验收。复用独立管理员会话和路线修订流程，提供文化与剧情草稿、预览、校验、发布和明确标注的测试模板。验证既有探索不随发布改版，编译微信及后台，区分工具验证和真机待验。

馆藏图、正式分镜及文化事实待核实。开发内容标明占位与待校订。暂缓页面位置微调、好友合作、PK 和完整用户管理。
