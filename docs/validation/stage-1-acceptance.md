# 阶段一验收清单

更新日期为 2026-11-11。验收入口为 HBuilderX「运行到微信开发者工具」生成的开发版。发行构建会关闭演示数据，阶段一查看样例应使用开发版。

阶段一交付的是小程序页面、地图交互和导航。路线、点位、已完成状态、日记、帖子及评论使用本地演示数据。页面会继续用于后续开发，后续阶段逐步接入云端接口。当前点位坐标、打卡范围和进度均不能用于真实到馆打卡或业务结算。

## 页面中的标识

| 标识 | 当前可以检查的内容 |
| --- | --- |
| 阶段一页面验收 · 本地演示数据 | 页面的布局、内容显示、已接通的跳转和返回；具体范围见标识下方文字 |
| 功能待开发 · 当前为说明页 | 能进入说明页、能返回；业务操作在标明的后续阶段实现 |
| 按钮带「待开发」 | 点击后显示功能说明或待开发提示；该业务当前没有成功提交或完成状态 |

地图上的「定位」已经接定位接口。开发者工具提供模拟坐标，真机定位及授权另行记录。首页蓝点表示这次定位成功返回的位置，灰色和彩色澳喵图钉表示演示点位状态。

## 本阶段需要验收的操作

按表内顺序操作即可。对于页面显示，可同时反馈字体、留白、图片、按钮大小和文案是否符合已确认的设计。

| 操作 | 通过标准 |
| --- | --- |
| 打开地图首页 | 地图和两侧入口可用，开发数据有标识；未选路线时底部路线条隐藏；能看到澳门演示图钉 |
| 点击灰色和彩色图钉 | 打开对应点位详情；返回后保留视野并出现相应选中样式；记录有示例标识 |
| 点击定位、放大和缩小，拖动地图 | 定位成功出现蓝点；缩放、拖动正常；定位失败有提示并可继续浏览，失败时不会产生虚假位置 |
| 路线 → 澳门路线详情 → 选择路线 | 回到该路线地图；只显示所选路线的点位；底部路线条默认收起 |
| 展开、收起当前路线条 | 任务正确显示；展开和收起不重置地图视野；「打卡说明 · 待开发」可进入说明页并返回 |
| 查看湖南路线，再清除当前路线 | 切换后显示湖南路线的点位和任务；清除后底栏隐藏；定位蓝点独立于路线选择 |
| 我的 → 档案 → 示例记录 | 页面内容可读；档案能打开对应记录；逐级返回可回到地图 |
| 社区 → 示例帖子 → 返回 | 文字、图片、评论显示正常；打开的是所点帖子；发帖显示待开发提示 |
| 剧情、旅伴、AI 猜图入口 | 剧情和旅伴显示待开发说明并可返回；AI 猜图提示敬请期待；无需测试章节解锁、加好友或发起 PK |
| 从二级页回到地图 | 所选路线、选中点位和地图视野保留；仅在明确选择另一条路线或点击定位时移动地图 |
| 缺少或错误的路线、点位、帖子参数 | 有可理解的空态和返回入口，页面不报错或永久空白；此项由开发方验证 |

开发方还负责微信编译、分包产物核对、包体统计、控制台错误、小屏与大屏遮挡检查。用户反馈侧重页面是否符合设计和上述点击流程是否顺畅。

## 进入阶段二的条件

1. 上表中的阶段一页面与导航通过检查。影响浏览的白屏、点错内容、无法返回、路线状态丢失或地图控件失效等问题已修复。
2. 已确认的布局和入口在实际微信页面中符合预期，未接通操作均能明确识别为待开发。
3. 开发方完成编译、分包及工具检查，并明确记录真机待确认项目。真实登录与上传需要的权限问题在阶段二联调时处理。

达到这些条件即可开始阶段二的代码工作。阶段一不以真实登录、真实提交打卡、帖子审核、合作或 PK 成功作为通过条件。阶段二云端联调仍按用户要求，在具体云端变更和部署内容准备好后另行取得部署授权。
